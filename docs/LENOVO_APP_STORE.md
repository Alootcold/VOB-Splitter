```
VOB Splitter 是一款 DVD VOB 无损分割工具。应用背景是 DVD 影片通常整盘发行，用户想单独提取其中某一集或某几章，而市面上的工具只有两条路：一是重新编码导出，画质掉一档、体积暴涨；二是按固定时长粗切一刀，章边界对不上。本软件只做字节级切片 —— 输出的每一个字节都来自原始码流，不重新编码、不重新封装，画质零损失。

一、切分原理
DVD 的每一章都是一条独立的 MPEG-2 sequence，章首会把时间戳（PTS）归零。因此在码流中「时间戳回落」精确对应一个章边界，并且该位置天然是一个随机访问点（序列头 + I 帧），可以安全切入。本软件据此定位切点，而不是按文件大小或时长估算。

二、主要功能
1. 按章节切分：读取 DVD 内置章节表自动定位各章边界，支持单个 VOB 文件或整张 VIDEO_TS 目录（多个 VTS 分卷会按序号自动排序，视为一条连续码流处理）。
2. 按等长时长切分：按固定秒数分段，用于没有章节表的素材。
3. 按指定时间点切分：手工输入秒数或 分:秒 形式的切点，多个切点以逗号分隔。
4. 字节级无损校验：每次运行计算源流的 SHA-256 与「各章按顺序拼接」后的 SHA-256 并逐位比对，同时生成 vobsplit-manifest.json 清单，记录源流与出流的字节数、哈希值，以及每一章的起止偏移、时长与 GOP 数量，使用者可自行复核。
5. 可选输出 MKV：调用使用者自行安装的 ffmpeg，以 -c copy 仅更换容器，不重编码，码流载荷保持逐字节一致。
6. 两种用法：图形界面与命令行。两者共用同一套核心算法，行为完全一致。图形界面左侧为控制栏（源、切分方式、输出、开始），右侧为章节表格与运行日志，顶栏显示无损校验徽章；命令行提供 scan（只扫描列章）、split（切分并自动校验）、verify（复核已有输出）三个子命令，支持 JSON 输出以便脚本调用。

三、技术特点
1. Python 与 Dart 两套完全独立的实现，核心算法逐行对应、测试用例一一对应，并有跨实现的交叉校验脚本自动比对两边的扫描结果、切分产物哈希与清单内容。
2. 全程离线运行：不联网、不注册账号、不收集任何个人信息，无遥测、无崩溃上报。
3. 安装与卸载界面为自绘深色风格，安装包支持静默安装与自选安装目录，卸载后无残留。
```

## 3. 文案（可直接粘贴）

### 一句话描述（21 字）

### 应用简介

```
VOB Splitter 把 DVD 的 VOB 码流按章节切成多个文件，输出的每一个字节都来自原始码流 —— 不重新编码、不重新封装。

按章节切分用的是 DVD 码流本身的特征：每一章都是一条独立的 MPEG-2 sequence，章首时间戳会归零，所以「时间戳回落」精确对应一个章边界，而且那个位置天然是随机访问点，可以安全切入。于是：
· 切点 = 码流里章首时间戳归零的那个 pack 边界
· 输出 = 输入码流的一段连续字节，原样复制
· 校验 = 源流 SHA-256 与「各章拼接 SHA-256」逐位比对，结果写进清单文件

主要功能：
· 三种切分方式：按 DVD 内置章节表 / 按等长时长 / 按指定时间点
· 字节级无损：每次运行都做 SHA-256 校验，用户可以自己复核
· 可选输出 MKV：调用 ffmpeg 的 -c copy 换容器，码流载荷同样逐字节一致
· 图形界面与命令行两种用法，结果一致

关于 ffmpeg：本版本**不内置** ffmpeg。切分 VOB 本身完全不需要它，只有「转 MKV」这一个可选功能需要用户自行安装 ffmpeg；不装也完全不影响按章节切分 VOB。后续版本会内置 ffmpeg，届时不需要用户另行安装。
```

## 8. 版本更新流程

上架之后要出新版本：

1. 改 `flutter/app/pubspec.yaml` 的 `version`，同步改 `flutter/app/installer/vobsplit.nsi` 里的 `APPVERSION`
2. `python tools/build_installers.py flutter` 出新安装包
3. 开放平台 → 应用列表 → 点「更新」→ 传新安装包 → 填「新版本特性」
4. **ffmpeg 说明要跟着改**：一旦内置了，就把简介和特性里的「本版本不内置 ffmpeg」改成「已内置，无需另行安装」

> 注意：首次提交后**不要随便删应用记录**，删了再提交会被判包名冲突，要走「应用认领」流程，很麻烦。

### 更新时会踩的两个坑

| 现象 | 原因 | 对策 |
|---|---|---|
| 更新提示「签名不一致」 | 新版本换了签名（代码签名证书换了/没签） | 必须先把**所有版本**下架，再按新签名重新创建；所以**从第一个版本起就用同一张代码签名证书**，别中途换 |
| 更新提示「已抓合作渠道的包正在审核中」 | 商店正在从其它渠道抓取该应用的包 | 审核周期 1~3 个工作日，等审核结束再更新，或联系客服驳回审核中的版本 |
